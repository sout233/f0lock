- Add Listen: audition the selected Point's range through a band-pass centred on its live frequency, so the band is heard as the rest of the chain leaves it rather than on its own.
- Drag the Listen control to set the window from 10 to 500 Hz either side (50 Hz by default), and click it to start or stop. The width is kept while listening is off, so it can be preset, and changes are heard immediately.
- Draw the audition window on the spectrum and dim the other Points while listening, so the one being heard is the only coloured one.
- Keep Listen out of the parameter list: the Point and the window width are editor state, so automation and saved projects are unaffected.
